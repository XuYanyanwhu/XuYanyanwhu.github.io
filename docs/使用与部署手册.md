# 教师主页使用与部署手册

更新时间：2026-05-28

## 1. 项目说明

本项目使用 Hugo 静态网站生成器和 Hugo Blox Academic 学术主页模板构建。主页内容面向学生、同行、评审专家和企业合作方，重点展示教师身份信息、研究方向、主要科研项目、代表性论文、专著专利获奖、学生培养和联系方式。

当前项目保留了两个早期版本备份目录：`bak1-ok1-纯文字列表/` 和 `bak2-ok2-增加图片轮播栏/`。备份目录不参与当前主页运行。正式维护和部署以 Hugo 版本为准，即主要修改 `content/`、`config/`、`data/`、`layouts/`、`static/` 等目录。当前已采用多页面结构，各栏目不再集中堆放在首页。

## 2. 环境要求

推荐环境：

- Hugo Extended 版本
- Node.js 与 npm
- 项目本地依赖 `node_modules/`

检查 Hugo：

```bash
hugo version
```

如果项目依赖缺失，可在项目根目录安装：

```bash
npm install
```

## 3. 本地预览

在项目根目录运行：

```bash
npm run dev
```

然后访问：

```text
http://localhost:1313/
```

如果 `1313` 端口被占用，可以换成其他端口，例如：

```bash
hugo server --bind 127.0.0.1 --port 1314 --disableFastRender
```

对应访问：

```text
http://localhost:1314/
```

## 4. 生成部署文件

运行：

```bash
npm run build
```

构建成功后，网站静态文件会输出到：

```text
public/
```

部署时只需要上传 `public/` 目录中的全部内容。`public/` 是构建产物，可以随时通过 Hugo 重新生成，不作为源码维护。

## 5. 内容维护指南

### 5.1 修改各栏目正文内容

首页入口内容位于：

```text
content/_index.md
```

各栏目内容分别位于：

```text
content/research/index.md
content/gallery/index.md
content/projects/index.md
content/publications/index.md
content/achievements/index.md
content/students/index.md
content/contact/index.md
```

修改时只需要打开对应页面文件编辑文字，不需要改动模板代码。

### 5.2 修改教师姓名、职称、单位、邮箱

教师基础信息位于：

```text
data/authors/me.yaml
```

可修改内容包括：

- `name`
- `role`
- `organizations`
- `interests`
- `profiles`
- `email`

头像文件位于：

```text
assets/media/authors/me.jpg
```

如需更换头像，建议保持文件名不变，直接替换该图片。

### 5.3 修改导航栏

顶部导航配置位于：

```text
config/_default/menus.yaml
```

每个导航项一般包含：

- `name`：页面显示文字
- `url`：跳转位置
- `weight`：排序权重，数字越小越靠前

例如跳转到科研项目页面：

```yaml
- name: 科研项目
  url: /projects/
  weight: 40
```

### 5.4 修改科研项目

科研项目位于：

```text
content/projects/index.md
```

格式建议保持普通文本序号：

```text
1. 项目来源，项目名称（No. 编号），起止时间，角色
2. 项目来源，项目名称（No. 编号），起止时间，角色
```

不要把每个项目写成卡片，当前页面采用标题加正文列表的学术展示风格。

### 5.5 修改代表性论文

代表性论文位于：

```text
content/publications/index.md
```

格式建议使用参考文献序号：

```text
[1] 作者. 题名. 期刊, 年份, 卷(期): 页码 [检索类型]
[2] 作者. 题名. 期刊, 年份, 卷(期): 页码 [检索类型]
```

英文期刊名可使用 Markdown 斜体：

```markdown
*IEEE Transactions on Service Computing*
```

### 5.6 修改已毕业学生表格

学生表格位于：

```text
content/students/index.md
```

表格格式如下：

```markdown
| 姓名 | 入学年份/硕博 | 本科院校 | 毕业去向 |
| --- | --- | --- | --- |
| 张三 | 2021 年入学硕士 | 武汉大学 | 华为 |
```

如需新增学生，复制一行并修改内容即可。

### 5.7 修改联系方式

联系方式位于：

```text
content/contact/index.md
```

当前联系方式不展示电话。如需修改邮箱或地址，直接编辑对应文本：

```markdown
Email: [xuyy@whu.edu.cn](mailto:xuyy@whu.edu.cn)
地址：武汉市洪山区珞喻路 129 号武汉大学信息学部
```

## 6. 图片维护指南

### 6.1 添加课题组风采图片

建议将图片放到：

```text
static/uploads/
```

例如新增：

```text
static/uploads/group-2026.jpg
```

在 `content/gallery/index.md` 中添加：

```html
<figure class="hb-carousel__slide">
  <img src="/uploads/group-2026.jpg" alt="课题组风采">
  <figcaption>课题组风采</figcaption>
</figure>
```

新增图片时，把新的 `figure` 放在 `.hb-carousel__track` 内部即可。小圆点和底部缩略图会由页面脚本自动生成，不需要手动维护。

### 6.2 图片命名建议

建议使用英文、数字和短横线命名：

```text
group-2026.jpg
lab-meeting-2026.jpg
award-2025.jpg
```

不建议使用空格或过长中文文件名，以免部署到服务器后出现路径问题。

## 7. 样式维护指南

自定义样式集中在：

```text
layouts/_partials/hooks/head-end/custom-site-style.html
```

当前样式重点包括：

- 科技蓝背景
- 顶部导航深色背景
- 正文白底高对比度显示
- 学术论文和项目列表的紧凑排版
- 表格边框与表头样式
- 课题组风采横向轮播、小圆点和缩略图

如需调整颜色，优先修改该文件中的 CSS 变量和颜色值。建议保持正文区域为浅色背景，避免论文、项目等长文本可读性下降。

## 8. 部署方式

### 8.1 部署到学院或课题组服务器

1. 在本地运行构建命令：

```bash
npm run build
```

2. 将 `public/` 目录中的所有文件上传到服务器网站目录。

3. 确认服务器入口可以访问 `index.html`。

4. 浏览器打开部署域名检查导航、图片、表格和链接。

### 8.2 部署到 GitHub Pages

推荐流程：

1. 将源码提交到 GitHub 仓库。
2. 使用 GitHub Actions 运行 Hugo 构建。
3. 将 `public/` 作为 Pages 发布内容。

如果采用手动方式，也可以本地构建后，将 `public/` 的内容推送到 GitHub Pages 分支。

### 8.3 部署到 Netlify 或 Vercel

构建命令：

```bash
hugo --minify
```

发布目录：

```text
public
```

如果平台构建时找不到 Tailwind 或 Pagefind，建议先确认 Node 依赖安装成功，或在平台中启用 npm install。

## 9. 常见问题

### 9.1 为什么根目录没有 index.html？

当前正式版本是 Hugo 站点，需要通过 Hugo server 预览，或打开构建后的 `public/index.html`。早期静态版入口已移入备份目录，不再放在项目根目录，避免和当前 Hugo 版本混淆。

### 9.2 修改内容后页面没有变化怎么办？

建议确认：

- 是否修改了 `content/` 下对应页面文件
- Hugo server 是否仍在运行
- 浏览器是否需要刷新
- 是否正在访问 `http://localhost:1313/`，而不是备份目录中的旧版页面

### 9.3 导航文字看不清怎么办？

导航文字颜色由自定义样式控制，位置在：

```text
layouts/_partials/hooks/head-end/custom-site-style.html
```

可检查其中关于 `nav`、`.navbar`、`header` 的颜色规则。

### 9.4 图片不显示怎么办？

建议检查：

- 图片是否放在 `static/uploads/`
- 页面引用路径是否以 `/uploads/` 开头
- 文件名大小写是否一致
- 文件名是否包含空格或特殊符号

### 9.5 如何删除电话？

电话信息只会在 `content/contact/index.md` 的联系方式页面中显示。当前版本已删除电话。如再次出现，搜索 `Tel` 或电话号码并删除对应行。

## 10. 交付检查清单

正式发布前建议检查：

- 首页姓名、职称、单位是否正确
- 个人简介是否准确
- 研究方向是否完整
- 科研项目编号、时间、角色是否无误
- 论文作者、题名、期刊、年份、检索标签是否无误
- 专著、专利、获奖信息是否无误
- 已毕业学生表格是否补全
- 邮箱和地址是否正确
- 图片是否正常显示
- 移动端和桌面端导航是否可用
- 构建命令是否通过

## 11. 推荐维护流程

每次修改建议按以下流程：

1. 修改 `content/` 下对应页面文件或相关配置文件。
2. 本地运行 Hugo server 预览。
3. 检查页面显示和链接跳转。
4. 运行 Hugo 构建命令。
5. 上传或发布 `public/`。
